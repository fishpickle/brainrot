# Prompt v5 Explanation Evaluation — 2026-07-30

## Evaluation Summary

**Prompt version:** v5

**Model:** GPT-5.6 Terra

**Method:** Nineteen translations submitted sequentially through the rendered
application UI. Tests 1–5 were run twice; tests 6–14 were run once.

**Directions:** Thirteen Standard→Gen Alpha runs and six Gen Alpha→Standard
runs

**API results:** 19 successful responses; no application errors

### Questions scored

1. Is the selected source span the shortest meaningful one?
2. Is its translated span the direct counterpart?
3. Does the reason explain everything inside those spans?
4. Were independent changes split without manufacturing unnecessary
   explanations?

`N/A` means no explanation was returned, so span-level questions could not be
scored.

## Overall Assessment

Prompt v5 improves explanation decomposition substantially. Multi-change inputs
usually receive separate explanation items, direct source-to-translation
correspondence is strong, and reasons are generally accurate and concise.

However, the primary Prompt v4 failure remains unresolved. Both repetitions of
“Finish your vegetables before dessert” selected the complete source and
translation, combining two explainable changes in one item. Several other runs
wrapped unchanged context around a changed word or selected a phrase whose
source and translation did not contain the same semantic material.

Prompt v5 is directionally better but should not yet be considered a stable
explanation-contract baseline.

## Key Findings

### 1. Decomposition improved, especially for clear multi-change inputs

Both room-cleaning runs and both train runs separated independent changes
cleanly. Tests 10 and 11 also decomposed multiple reverse idioms correctly.

### 2. Minimum-span selection remains inconsistent

Prompt v5 often selects a complete clause around a single changed verb. The
clearest examples are:

- “Put your shoes by the door” rather than “Put”
- “gotta dip” rather than “dip”
- The complete vegetables sentence rather than its distinct transformations

### 3. Reasons are stronger than span selection

Most reasons correctly explain the intended transformation. Failures occur
primarily when an overly broad or semantically mismatched pair makes it
impossible for the reason to cover everything selected.

### 4. Holistic exceptions work

The proverb and “main character energy” examples correctly use broad spans
because their meanings operate as integrated constructions. Tightening minimum
spans must preserve this exception.

### 5. Empty explanations are not reliably ambiguity-aware

The unchanged Standard English test correctly returned no explanations, but the
ambiguous “in the void” test also returned none. The model needs a stronger
distinction between trivial no-op input and unresolved figurative ambiguity.

## Recommendation

Do not promote Prompt v5 as stable yet. Make one narrow explanation-contract
revision and rerun this exact suite:

1. Explicitly exclude words that are identical in meaning and wording from
   phrase pairs unless they are required to understand an indivisible idiom.
2. Require each selected source and translated span to contain the same
   semantic information.
3. If a reason discusses only one changed word, require the phrase pair to
   isolate that word or the smallest grammatical unit containing it.
4. Reiterate that unresolved figurative ambiguity requires an explanation even
   when the translation remains unchanged.

The translation contract should remain untouched during that revision.

## Findings

### 1. The ambiguity requirement now works

Test 12 is the clearest success. V5 left the figurative phrase unchanged
without comment. V5.1 preserves the uncertainty and explains it without
inventing context. Test 14 still returns no explanation, so the stronger rule
did not create blanket over-explanation.

### 2. Decomposition and reason coverage improved

The paired train runs, multiple reverse idioms, and contrasting evaluation
terms are consistently separated. Q4 rose from 63% to 84%, and Q3 rose from
71% to 83%.

### 3. Minimum-span discipline improved only modestly

The model still wraps unchanged words around a single changed term in Tests 4a
and 9. It also occasionally selects a whole sentence when two local
transformations could be explained independently, as in Test 1a.

### 4. Semantic-span alignment remains the largest unresolved weakness

Tests 2b, 5a, and 5b place information on only one side of a pair. The new
contract states the rule explicitly, but complex sentences still invite the
model to pair rhetorically coherent phrases rather than semantically equivalent
spans.

## Recommendation

Prompt v5.1 is a meaningful improvement but should not yet be marked stable.
Keep it as the current candidate and run one more evaluation with multiple
samples per input before revising the contract again. The next decision should
be based on failure frequency:

1. If semantic mismatch repeats, add compact positive and negative examples of
   aligned spans rather than more abstract rules.
2. If broad but semantically aligned spans dominate, consider accepting them
   when the reason is complete; the product value of word-perfect span
   minimality may not justify further prompt growth.
3. Retain the explicit ambiguity rule. It fixed the clearest v5 omission
   without causing unnecessary explanations in the control case.
