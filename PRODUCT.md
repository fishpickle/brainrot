# Gen Alpha Translator

## Vision

Translate between standard American English and Gen Alpha slang while preserving meaning, tone, and intent.

Unlike joke generators, this should feel like a real translation tool.

## Users

- Parents
- Teachers
- Millennials
- Curious Gen X
- Kids translating for adults

## MVP

- Adult → Gen Alpha
- Gen Alpha → Adult
- Intensity:
  - Mild
  - Cooked
  - Ohio Max
- Explain why certain phrases were translated
- Copy button
- Responsive
- Dark mode

## Non-goals

- User accounts
- Saving history
- Database
- Social sharing

## Success

A user can paste a paragraph, translate it in under 5 seconds, understand *why* the translation changed, and copy the result.
